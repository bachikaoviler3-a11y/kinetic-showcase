# Ultra-Smooth Kinetic 3D Showcase & Editorial Journey (White-Label)

A pitch-ready, white-label 3D kinetic product showcase engineered with WebGL, GSAP ScrollTrigger, Lenis smooth scrolling, and an interactive editorial storytelling narrative.

## Features
- **Zero Third-Party Branding**: Clean white-label typography (`YOUR BRAND`), procedural offscreen metallic textures, and placeholder boutique packaging.
- **Kinetic 3D Hero**: Real-time cursor repulsion physics with a 400px force-field and organic float physics.
- **720° Dual-Color Variant Transitions**: Seamless variant switching between Emerald Essence and Cobalt Mist with rotational spin and camera easing.
- **Editorial Scrollytelling**: 5 interactive chapters (Overview, The Vessel, Formula & Ingredients, Craft & Ethos, Boutique Edition Selection) with sticky 3D model docking.
- **Bilingual Engine**: Instant smooth toggle between Thai (TH) and English (EN).
- **Typography**: Editorial Modern (`Syne` + `Prompt`).
